S.T.E.A.M — Imprimerie Médicale de Noël (1927)
================================================

Contexte
--------
Une imprimerie médicale du début du XXe siècle prépare un tirage spécial de Noël.
Des agents d’Hadès Corp ont mélangé les plaques d’impression.
Votre mission : reconstituer et ordonner correctement les éléments.

Objectif
--------
Assembler les 8 éléments dans le bon ordre pour révéler le code :
F E T E S X A R

Utilisation
-----------
- Ouvrez index.html dans un navigateur moderne
- Glissez-déposez les pièces
- Lorsque l’ordre est correct, le code final s’affiche

Technologie
-----------
- HTML / CSS / JavaScript pur
- Aucune dépendance externe

Univers
-------
S.T.E.A.M — Agence Temporelle
Archives Sterenna
